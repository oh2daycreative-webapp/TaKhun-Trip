## 2. Main Objective

เว็บแอป **Takhun Trip** มีเป้าหมายเพื่อเป็นศูนย์รวมข้อมูลการท่องเที่ยวของอำเภอบ้านตาขุนและพื้นที่ใกล้เคียง โดยเน้นการใช้งานง่ายบนมือถือ มีแผนที่นำทาง เส้นทางแนะนำ ข้อมูลสถานที่ กิจกรรม สินค้าชุมชน และระบบหลังบ้านให้ผู้ดูแลสามารถจัดการข้อมูลได้จริง

วัตถุประสงค์หลัก:

1. นำเสนอเส้นทางท่องเที่ยวอำเภอบ้านตาขุนอย่างเป็นระบบ
2. เชื่อมโยงจุดท่องเที่ยวหลัก 4 จุดตามแผนงาน
3. แสดงแผนที่พร้อมหมุดสถานที่และเส้นทางแนะนำ
4. สนับสนุนการวางแผนทริปของนักท่องเที่ยว
5. ส่งเสริมสินค้าชุมชน กิจกรรมท้องถิ่น และบริการในพื้นที่
6. รองรับระบบหลังบ้านสำหรับเพิ่ม ลบ แก้ไขข้อมูล
7. ใช้งานได้จริงทั้งบนมือถือ แท็บเล็ต และคอมพิวเตอร์

---

## 3. Product Vision

**Takhun Trip** ต้องเป็นเว็บแอปที่นักท่องเที่ยวเปิดขึ้นมาแล้วสามารถตอบคำถามเหล่านี้ได้ทันที:

- บ้านตาขุนมีที่เที่ยวอะไรบ้าง
- เส้นทางหลักควรเที่ยวจากจุดไหนไปจุดไหน
- จุดท่องเที่ยวอยู่ตรงไหน
- กดนำทางไปอย่างไร
- มีเบอร์ติดต่อใคร
- มีกิจกรรมชุมชนอะไรน่าสนใจ
- มีสินค้าชุมชนหรือบริการอะไรบ้าง
- มีสถานที่ใกล้เคียงที่ควรไปต่อหรือไม่

ระบบต้องไม่ใช่แค่เว็บประชาสัมพันธ์ทั่วไป แต่ต้องทำหน้าที่เป็น **Travel Companion** หรือ “ผู้ช่วยเที่ยวบ้านตาขุน” ในรูปแบบที่ใช้งานง่ายและดูพรีเมี่ยม

## 4. Target Users

### 4.1 Tourist Users

นักท่องเที่ยวทั่วไปที่ต้องการค้นหาข้อมูลสถานที่ท่องเที่ยว แผนที่ เส้นทาง กิจกรรม และข้อมูลติดต่อ

### 4.2 On-site Mobile Users

นักท่องเที่ยวที่เดินทางอยู่ในพื้นที่จริง และต้องการใช้งานจากมือถือเพื่อดูแผนที่ กดนำทาง โทรติดต่อ หรือค้นหาสถานที่ใกล้เคียง

### 4.3 Community Operators

กลุ่มวิสาหกิจชุมชน ร้านค้า ผู้ให้บริการรถเช่า แพ ร้านอาหาร คาเฟ่ หรือผู้ประกอบการท่องเที่ยวในพื้นที่

### 4.4 Admin Users

เจ้าหน้าที่หรือผู้รับผิดชอบโครงการที่ต้องการจัดการข้อมูลผ่านระบบหลังบ้าน

- สโลแกน

- การ์ดเส้นทางหลัก 4 จุด
- สถานที่ยอดนิยม

### 6.2 Interactive Map

ระบบแผนที่เป็นฟังก์ชันหลักของเว็บแอป

#### Required Features

- แสดงหมุดสถานที่ท่องเที่ยว
- แสดงเส้นทางแนะนำจากจุดที่ 1 ถึงจุดที่ 4 ตามลำดับ
- แยกสถานที่เป็น 2 กลุ่ม:
  1. สถานที่ท่องเที่ยวอำเภอบ้านตาขุน
  2. สถานที่ท่องเที่ยวในอำเภอใกล้เคียง
- มีตัวกรองประเภทสถานที่
- มี Popup Card เมื่อกดหมุด
- มีปุ่ม “ดูรายละเอียด”
- มีปุ่ม “นำทาง”
- มีปุ่ม “โทร” เมื่อสถานที่มีเบอร์โทร
- รองรับการแสดงผลบนมือถืออย่างสมบูรณ์

#### Suggested Map Categories

- จุดท่องเที่ยวหลัก
- ธรรมชาติ
- จุดชมวิว
- กิจกรรมชุมชน
- สินค้าชุมชน
- ร้านอาหาร / คาเฟ่
- ที่พัก / แพ
- วัด / วัฒนธรรม
- อำเภอใกล้เคียง

#### Map Technology

แนะนำให้ใช้:

- Leaflet.js
- OpenStreetMap

เหตุผล:

- ใช้งานฟรี
- ไม่ซับซ้อน
- เหมาะกับเว็บแอปประชาสัมพันธ์
- ไม่ต้องผูกค่าใช้จ่ายระยะยาว

### 6.3 Route Explorer

หน้าแสดงเส้นทางท่องเที่ยวหลัก

#### Required Features

- แสดงเส้นทางท่องเที่ยวบ้านตาขุน 4 จุดหลัก
- แสดงลำดับการเดินทาง
- แสดงข้อมูลเด่นของแต่ละจุด
- แสดงกิจกรรมใกล้เคียง
- มีปุ่มเปิดแผนที่
- มีปุ่มแชร์เส้นทาง
- มีรูปภาพประกอบแต่ละจุด
- มีข้อมูลเบอร์ติดต่อ ถ้ามี

#### Main Route

เส้นทางหลักต้องเรียงลำดับดังนี้:

1. วิสาหกิจชุมชนท่องเที่ยวเขื่อนรัชชประภา
2. วิสาหกิจชุมชนท่องเที่ยวบ้านเชี่ยวหลาน
3. วิสาหกิจชุมชนพรุไทย ฮันนี่บี
4. วิสาหกิจชุมชนท่องเที่ยวเชิงอนุรักษ์บ้านเขาเทพพิทักษ์

  - ครึ่งวัน

## 10. Non-functional Requirements

### 10.1 Performance

- หน้าแรกต้องโหลดเร็ว
- รูปภาพต้องถูกบีบอัดก่อนใช้งานจริง
- ข้อมูลจาก Google Apps Script ควรมี Cache
- ไม่ควรโหลดข้อมูลทุกอย่างพร้อมกันถ้าไม่จำเป็น

### 10.2 Responsive

- Public pages ต้องออกแบบแบบ Mobile-first
- Admin pages ต้องใช้งานได้ทั้งคอมพิวเตอร์และมือถือ
- ขนาดปุ่มต้องกดง่ายบนมือถือ

### 10.3 Accessibility

- สีข้อความต้องอ่านง่าย
- ปุ่มต้องมีข้อความหรือ aria-label
- รูปภาพสำคัญควรมี alt text
- ไม่ใช้ตัวอักษรเล็กเกินไป

### 10.4 Security

- Admin API ต้องตรวจสิทธิ์
- ฟอร์มต้อง validate ก่อนส่ง
- ห้ามเก็บรหัสผ่านแบบ plain text ถ้าหลีกเลี่ยงได้
- API response ต้องไม่เปิดเผยข้อมูลที่ไม่จำเป็น

### 10.5 Maintainability

- โค้ดต้องแยกไฟล์เป็นระบบ
- ห้ามรวม JavaScript ทั้งหมดไว้ใน HTML
- ห้าม hardcode ข้อมูลที่ควรมาจาก Google Sheets
- ชื่อฟังก์ชันต้องสื่อความหมายชัดเจน

## 13. Acceptance Criteria

ระบบจะถือว่าผ่านเกณฑ์เบื้องต้นเมื่อ:

1. เปิดหน้าเว็บได้บน Cloudflare Pages
2. หน้าเว็บแสดงผลถูกต้องบนมือถือ
3. แผนที่แสดงหมุดสถานที่ได้
4. เส้นทางหลัก 4 จุดแสดงตามลำดับ
5. ปุ่มนำทางเปิด Google Maps ได้
6. หน้ารายละเอียดสถานที่แสดงข้อมูลครบ
7. Trip Planner ใช้งานได้แบบง่าย
8. Admin Login ทำงานได้
9. Admin เพิ่ม ลบ แก้ไขข้อมูลสถานที่ได้
10. ข้อมูลจาก Admin แสดงผลบนหน้า Public ได้
11. รีวิวต้องรออนุมัติก่อนแสดงผล
12. ภาษาไทยและอังกฤษทำงานได้
13. ไม่มี error หลักใน browser console
14. ไม่ทำฟังก์ชันนอกขอบเขต MVP จนทำให้ระบบซับซ้อนเกินไป

## 14. Codex Working Rules

เมื่อใช้ Codex พัฒนาโปรเจกต์นี้ ให้ยึดกติกาดังนี้:

1. อ่าน `README.md` และ `docs/APP_SPEC.md` ก่อนเริ่มงานทุกครั้ง
2. ทำงานทีละระบบ ไม่แก้หลายระบบพร้อมกัน
3. ก่อนแก้โค้ดให้สรุปแผนสั้น ๆ
4. หลังแก้โค้ดให้สรุปไฟล์ที่แก้
5. ห้ามเปลี่ยนชื่อไฟล์หลักเอง
6. ห้ามเพิ่ม framework ใหม่โดยไม่ได้รับอนุญาต
7. ห้ามลบฟังก์ชันเดิมโดยไม่ตรวจสอบผลกระทบ
8. ห้าม hardcode ข้อมูลสถานที่ใน HTML ถ้าข้อมูลควรมาจาก Google Sheets
9. ต้องรักษาแนวทาง Mobile-first
10. ต้องรักษาแนวทาง UX/UI ของ Takhun Trip
11. ต้องทดสอบหน้าเว็บหลังแก้ไขทุกครั้ง
12. ถ้าไม่แน่ใจ ให้ถามก่อน ไม่เดา
