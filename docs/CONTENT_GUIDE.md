# CONTENT_GUIDE.md — Takhun Trip

เอกสารนี้กำหนดแนวทางการเขียนเนื้อหาทั้งภาษาไทยและภาษาอังกฤษสำหรับเว็บแอป **Takhun Trip** เพื่อให้ทุกหน้าของเว็บมีน้ำเสียงเดียวกัน อ่านง่าย น่าเที่ยว ดูพรีเมี่ยม และเหมาะกับการประชาสัมพันธ์การท่องเที่ยวบ้านตาขุน

เอกสารนี้ใช้ควบคุมการเขียนเนื้อหาในหน้าเว็บ ระบบ Admin/CMS, ข้อมูลสถานที่, เส้นทางท่องเที่ยว, สินค้าชุมชน, กิจกรรม, รีวิว, ปุ่ม, ข้อความแจ้งเตือน และข้อความภาษาอังกฤษ

---

## 1. Content Vision

เนื้อหาของ **Takhun Trip** ต้องทำให้ผู้ใช้รู้สึกว่า:

> “บ้านตาขุนเที่ยวง่าย มีเสน่ห์ มีเรื่องราว และมีจุดหมายที่น่าไปสัมผัสจริง”

เนื้อหาต้องไม่ใช่ข้อความแห้ง ๆ แบบเอกสารราชการ แต่ต้องเป็นภาษาเชิงท่องเที่ยวที่อ่านแล้วเห็นภาพ เข้าใจเร็ว และช่วยให้ผู้ใช้ตัดสินใจเดินทางได้ง่าย

---

## 2. Brand Voice

### 2.1 บุคลิกของภาษา

ภาษาในเว็บควรมีบุคลิกดังนี้:

- สดใส
- ชวนเที่ยว
- อบอุ่น
- น่าเชื่อถือ
- กระชับ
- อ่านง่าย
- มีภาพจำ
- ไม่เว่อร์เกินจริง
- ไม่แข็งแบบราชการ
- ไม่ขายของจนเกินไป

### 2.2 น้ำเสียงหลัก

ใช้โทน:

```text
พรีเมี่ยม + เป็นมิตร + ชวนออกเดินทาง + เคารพวิถีชุมชน
```

### 2.3 สิ่งที่ต้องหลีกเลี่ยง

ห้ามใช้ภาษาที่:

- ยาวเกินไป
- เป็นทางการเกินไป
- เหมือนคัดจาก TOR หรือเอกสารราชการ
- โฆษณาเกินจริง เช่น “ดีที่สุดในโลก”, “สวยที่สุดในประเทศไทย”
- ใช้คำซ้ำ ๆ แบบ AI เช่น “สัมผัสประสบการณ์อันน่าประทับใจ” ทุกหน้า
- ใช้คำฟุ่มเฟือย
- ใช้ภาษากำกวมจนผู้ใช้ไม่รู้ว่าต้องทำอะไรต่อ
- ใส่ข้อมูลที่ยังไม่ยืนยัน เช่น ราคา เวลาเปิดปิด หรือพิกัด โดยไม่มีหมายเหตุ

## 3. Core Message

ข้อความหลักที่ควรสื่อซ้ำทั้งระบบ:

```text
Takhun Trip คือผู้ช่วยวางแผนเที่ยวบ้านตาขุน ที่รวมแผนที่ เส้นทาง จุดท่องเที่ยว กิจกรรม และของดีชุมชนไว้ในที่เดียว
```

แนวคิดหลัก:

- เที่ยวบ้านตาขุนง่ายขึ้น
- มีเส้นทางแนะนำชัดเจน
- มีแผนที่และปุ่มนำทาง
- เชื่อมโยงธรรมชาติ เขื่อน ภูเขา ชุมชน และสินค้า
- เปิดมือถือแล้วเที่ยวได้ทันที

## 5. Thai Writing Style

### 5.1 หลักการเขียนภาษาไทย

ให้ใช้ภาษาไทยที่:

- อ่านง่าย
- ประโยคไม่ยาวเกินไป
- มีจังหวะเหมือนภาษาประชาสัมพันธ์ท่องเที่ยว
- ใช้คำไทยก่อนคำอังกฤษ
- ถ้าต้องใช้คำอังกฤษ ให้ใช้เท่าที่จำเป็น
- ข้อมูลสำคัญต้องอยู่ต้นประโยค
- ปุ่มและเมนูต้องสั้นมาก

### 5.2 ความยาวที่แนะนำ

| ประเภทข้อความ | ความยาวที่แนะนำ |
|---|---:|
| ชื่อเมนู | 1–3 คำ |
| ปุ่ม | 1–4 คำ |
| หัวข้อ Section | 4–9 คำ |
| คำอธิบายสั้นในการ์ด | 1–2 บรรทัด |
| รายละเอียดสถานที่ | 80–180 คำ |
| รายละเอียดกิจกรรม | 60–150 คำ |
| คำแนะนำก่อนเที่ยว | เป็น bullet สั้น ๆ |

### 5.3 ตัวอย่างประโยคที่ดี

```text
ล่องเรือชมทะเลสาบสีเขียวมรกต ท่ามกลางภูเขาหินปูนและบรรยากาศเงียบสงบของเขื่อนรัชชประภา
```

```text
จุดถ่ายภาพยอดนิยมของบ้านตาขุน ที่มองเห็นสะพานแขวนและภูเขารูปหัวใจได้ในมุมเดียว
```

```text
ชิมน้ำผึ้งสดจากรวง เรียนรู้วิถีการเลี้ยงผึ้ง และเลือกซื้อผลิตภัณฑ์ชุมชนกลับเป็นของฝาก
```

### 5.4 ตัวอย่างประโยคที่ควรหลีกเลี่ยง

ไม่ควรใช้:

```text
สถานที่แห่งนี้เป็นสถานที่ท่องเที่ยวที่มีความสวยงามมาก ๆ และเป็นสถานที่ที่นักท่องเที่ยวควรมาเยี่ยมชมเป็นอย่างยิ่ง
```

ปรับเป็น:

```text
จุดชมวิวบรรยากาศดี เหมาะสำหรับแวะพัก ถ่ายภาพ และชมธรรมชาติของบ้านตาขุน
```

## 6. English Writing Style

### 6.1 English Tone

ภาษาอังกฤษควรเป็น:

- Clear
- Simple
- Warm
- Travel-friendly
- Not too formal
- Easy for international tourists

### 6.2 English Rules

- ใช้ประโยคสั้น
- หลีกเลี่ยงคำยาก
- ไม่แปลตรงตัวจนแข็ง
- ใช้คำที่นักท่องเที่ยวเข้าใจง่าย
- ชื่อเฉพาะภาษาไทยสามารถทับศัพท์ได้ พร้อมคำอธิบายภาษาอังกฤษ

```text
Take a boat trip across the emerald lake, surrounded by limestone mountains and the peaceful scenery of Ratchaprapha Dam.
```

## 10. Place Content Template

ใช้ template นี้สำหรับเขียนรายละเอียดสถานที่

### 10.1 Place Short Description

รูปแบบ:

```text
[จุดเด่นหลัก] เหมาะสำหรับ [กิจกรรม/กลุ่มผู้ใช้] พร้อม [สิ่งที่ทำได้]
```

ตัวอย่าง:

```text
จุดเริ่มต้นเที่ยวเขื่อนรัชชประภา พร้อมบริการรถเช่าและเส้นทางเชื่อมต่อไปยังทะเลสาบเชี่ยวหลาน
```

### 10.2 Place Detail Structure

รายละเอียดสถานที่ควรเรียงแบบนี้:

```text
1. เปิดด้วยภาพจำหรือจุดเด่น
2. อธิบายว่าที่นี่มีอะไร
3. บอกกิจกรรมที่ทำได้
4. บอกว่าเหมาะกับใคร
5. ปิดด้วยคำแนะนำก่อนเดินทาง
```

### 10.3 Place Detail Example

```text
วิสาหกิจชุมชนท่องเที่ยวเขื่อนรัชชประภาเป็นจุดเริ่มต้นสำคัญของการเที่ยวบ้านตาขุน เหมาะสำหรับนักท่องเที่ยวที่ต้องการเชื่อมต่อไปยังเขื่อนรัชชประภา ทะเลสาบเชี่ยวหลาน และกิจกรรมรอบพื้นที่

บริเวณนี้มีบริการรถเช่า รถจักรยาน รถจักรยานไฟฟ้า รถสามล้อไฟฟ้า และรถกอล์ฟ ช่วยให้นักท่องเที่ยวเดินทางต่อไปยังจุดต่าง ๆ ได้สะดวกขึ้น ใกล้กันยังมีร้านกาแฟ ร้านอาหาร จุดชมวิว และเส้นทางสู่กิจกรรมล่องเรือชมทะเลสาบสีเขียวมรกต

เหมาะสำหรับเริ่มต้นทริป ถ่ายภาพ ชมวิว และวางแผนเดินทางต่อไปยังชุมชนอื่น ๆ ในบ้านตาขุน
```

### 10.4 Place Detail English Example

```text
Ratchaprapha Dam Community Tourism Enterprise is a convenient starting point for exploring Ban Ta Khun. It connects visitors to Ratchaprapha Dam, Cheow Lan Lake, local cafés, viewpoints, and nearby community routes.

Visitors can find local transport services such as bicycles, electric bicycles, electric tricycles, and golf carts. It is a good place to begin your trip, plan your route, and continue toward the emerald lake and surrounding attractions.
```

```text
เป็นที่รู้จักกันอย่างแพร่หลายทั่วทุกสารทิศ
```

### 25.3 Better Replacements

| Avoid | Use Instead |
|---|---|
| สวยที่สุด | วิวสวย / บรรยากาศดี / จุดชมวิวเด่น |
| ห้ามพลาด | น่าแวะ / แนะนำให้แวะ |
| สัมผัสประสบการณ์อันน่าประทับใจ | ลองทำกิจกรรม / เรียนรู้ / แวะชม |
| ครบวงจร | รวมไว้ในที่เดียว / ใช้งานง่าย |
| มีชื่อเสียงมาก | เป็นจุดที่นักท่องเที่ยวนิยมแวะ |

## 26. Content Formatting Rules

### 26.1 Paragraph

- 1 ย่อหน้าไม่ควรเกิน 3–4 บรรทัดบนมือถือ
- รายละเอียดที่มีหลายประเด็นให้ใช้ bullet
- หลีกเลี่ยงประโยคซ้อนยาว

### 26.2 Bullet Points

ใช้ bullet สำหรับ:

- กิจกรรม
- คำแนะนำก่อนเที่ยว
- สิ่งอำนวยความสะดวก
- ข้อควรระวัง
- จุดเด่น

### 26.3 Phone Number

รูปแบบ:

```text
083 789 4493
087 270 0774
081 396 8145
084 843 7924
```

### 26.4 Date

รูปแบบไทย:

```text
1 สิงหาคม 2569
```

รูปแบบเก็บข้อมูล:

```text
2026-08-01
```

### 26.5 Time

รูปแบบไทย:

```text
10.00–16.00 น.
```

English:

```text
10:00 AM – 4:00 PM
```

## 27. Content Workflow

เมื่อเพิ่มข้อมูลใหม่ใน Admin ควรตรวจสอบตามลำดับ:

```text
1. ชื่อสถานที่ถูกต้อง
2. มีคำอธิบายสั้น
3. รายละเอียดไม่ยาวเกินไป
4. มีเบอร์โทรหรือช่องทางติดต่อ ถ้ามี
5. มีลิงก์ Google Maps ถ้ามี
6. มีพิกัด ถ้าจะปักหมุด
7. มีรูปภาพประกอบ
8. มีสถานะเผยแพร่ถูกต้อง
9. ภาษาอังกฤษ fallback ได้
10. ไม่มีข้อมูลที่ยังไม่ยืนยันโดยไม่ใส่หมายเหตุ
```

## 28. Codex Instructions for Content

เมื่อใช้ Codex สร้างหรือแก้เนื้อหา ให้ยึดกติกานี้:

1. อ่าน `docs/CONTENT_GUIDE.md` ก่อนเขียนข้อความทุกครั้ง
2. ใช้น้ำเสียงสดใส พรีเมี่ยม เป็นมิตร และชวนเที่ยว
3. ห้ามเขียนแบบเอกสารราชการ
4. ห้ามโฆษณาเกินจริง
5. ข้อมูลที่ไม่แน่ใจต้องใส่ข้อความรอยืนยันหรือถามก่อน
6. ปุ่มต้องใช้ข้อความสั้น
7. Card ต้องใช้คำอธิบายสั้น ไม่ยัดข้อความยาว
8. รายละเอียดสถานที่ต้องอ่านง่ายบนมือถือ
9. ภาษาอังกฤษต้องเป็นธรรมชาติ ไม่แปลตรงตัวเกินไป
10. ชื่อ field และ category ต้องสอดคล้องกับ `DATA_SCHEMA.md`
11. ถ้าต้องเพิ่มข้อความระบบใหม่ ให้เพิ่มในแนวทางนี้ก่อน
12. ถ้าไม่แน่ใจ ให้ถามก่อน ไม่เดา

## 29. Content Acceptance Criteria

เนื้อหาจะถือว่าผ่านเมื่อ:

1. อ่านง่ายบนมือถือ
2. ข้อความไม่แข็งแบบราชการ
3. ปุ่มสั้นและชัดเจน
4. ชื่อสถานที่ถูกต้อง
5. รายละเอียดช่วยให้นักท่องเที่ยวตัดสินใจได้
6. มีข้อมูลติดต่อหรือคำแนะนำเมื่อจำเป็น
7. ไม่มีการอ้างข้อมูลที่ยังไม่ยืนยันแบบฟันธง
8. ภาษาไทยและอังกฤษใช้คนละสำนวนที่เหมาะสม ไม่แปลทื่อ
9. ข้อความระบบมี Loading / Empty / Error / Success ครบ
10. สอดคล้องกับภาพลักษณ์ Takhun Trip

## 30. Final Content Direction

เนื้อหาของ **Takhun Trip** ต้องทำให้เว็บแอปดูเป็นเครื่องมือท่องเที่ยวจริง ไม่ใช่แค่ฐานข้อมูลสถานที่
